# **App Name**: RetroCinema Navigator 2.0

## Core Features:

- Universal Video URL Input: Accepts any URL, integrating videos from Youtube, Vimeo, or direct links to video files.
- Full Cinematic Experience: Provides a distraction-free viewing experience with no bezel, frame elements or advertisements.
- Adjustable Viewing Screen Size: Enables users to change the size of the viewing screen from thumbnail to full screen with a smooth transition.
- Theme Selection: Offers immersive themes like Home, Movie Theater, and Drive-In, each with elements to enhance the viewing environment.
- YouTube Playlist Integration: Integration for loading Youtube playlists and allowing seamless preloaded videos directly in the video player.
- AI Viewing Recommendations: Generates personalized viewing recommendations based on user's viewing history, and provides smart playback suggestions via AI tool.
- Seamless Video Playback: Automatically loads the video based on URL insertion by user with the video staying on the main web page for easy use.

## Style Guidelines:

- Primary color: Deep purple (#663399) for a futuristic and luxurious feel.
- Background color: Dark gray (#222222) to enhance contrast and focus on the video content.
- Accent color: Electric blue (#7DF9FF) to highlight interactive elements and provide a modern touch.
- Font: 'Space Grotesk', a modern sans-serif font with a tech-inspired vibe suitable for both headlines and body text.
- Use sleek, neon-style icons for video controls and theme selection.
- Glassmorphism design for panels to create a modern, futuristic aesthetic.
- Subtle particle animations for the background that respond to user interaction.
